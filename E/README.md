# Trabalhos laboratoriais de Eletrónica

Esta pasta reúne projetos desenvolvidos no âmbito dos trabalhos laboratoriais de Eletrónica. Os projetos estudam circuitos CMOS através de esquemas e simulações no LTspice.

## Projetos

### [TLab1 — Circuitos CMOS](TLab1/README.md)

Implementação e validação lógica da função `Y = A · ¬B · ¬C`, usando multiplexers com portas de transmissão e circuitos integrados CD4007. Inclui esquemas LTspice e simulações das combinações das entradas.

### [TLab2 — Atrasos de propagação](TLab2/README.md)

Estudo da resposta temporal de circuitos CMOS, com medições dos atrasos de subida e descida, comparação de sinais entre estágios e testes com carga capacitiva.

Consulte o README de cada projeto para conhecer os ficheiros principais e as instruções de simulação.
